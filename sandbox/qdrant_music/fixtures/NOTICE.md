# Dataset Notice

## Chart facts

The frozen chart facts in
`billboard_hot_100_2024-06-01_top50.json` represent ranks 1–50 of the
Billboard Hot 100 chart dated 2024-06-01.

- Official chart page:
  https://www.billboard.com/charts/hot-100/2024-06-01/
- Reproducible JSON snapshot used for transcription:
  https://raw.githubusercontent.com/mhollingshead/billboard-hot-100/main/date/2024-06-01.json

Billboard chart names and chart data belong to their respective owner. This
small factual snapshot is included only as a non-commercial educational
fixture. It contains no audio, lyrics, artwork, or review excerpts.

## Community descriptions

Community tags are a manually reviewed educational taxonomy informed by common
genre, mood, and performance descriptors and MusicBrainz's community-tag model.
They are not represented as a live or complete MusicBrainz export. Each
description is original, short, and deliberately avoids lyrics and copied
reviews.

MusicBrainz documentation and licensing:

- https://musicbrainz.org/doc/MusicBrainz_API
- https://musicbrainz.org/doc/About/Data_License

If the fixture is refreshed, preserve the chart date, source URL, acquisition
date, description method, and review status in the JSON metadata.
