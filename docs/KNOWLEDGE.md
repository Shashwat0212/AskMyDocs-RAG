# Documentation Knowledge

## Current Contents

This folder contains the repository's project documentation, including
Jira-to-repository tracking rules, current status, future prospects, roadmap,
engineering workflow, development environment guidance, coding standards,
AI-agent workflow, active and superseded decisions, architecture notes and
detailed epic step plans, operations notes, executable tutorials, API and
evaluation placeholders, and owner-provided source documents.

## Responsibilities

Documentation in this folder governs how the project is planned and implemented. Root `starter.md` provides the maintained first-read summary and routes each task to these detailed sources. The `project-governance` branch holds the live planning view, while `main` holds the latest approved checkpoint. `docs/source_documents/` contains the owner-provided source-of-truth DOCX files, while `AGENTS.md` is the canonical AI-agent instruction file at the repository root.

## Update Notes

Update this file when the documentation structure changes. `tutorials/`
contains phase-aligned executable learning guides. `EPIC_1_JIRA_REFERENCE.md`
records the approved Epic 1 structure but does not replace Jira execution
state. Follow `docs/PROJECT_TRACKING.md` for synchronization and update the
starter, status, prospects, and decisions when their source information changes.
