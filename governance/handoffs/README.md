# Governance Handoffs

A handoff is the only approved route from this standalone planning branch to an implementation branch.

Each handoff must contain:

- Title and approval date.
- Governance commit SHA.
- Target epic and ticket IDs.
- Target epic branch.
- Scope and explicit exclusions.
- Acceptance criteria.
- Source governance files.
- Documentation that implementation must update.

Handoffs should be small enough to copy or reproduce without bringing the governance-only directory structure into the implementation branch.

After promotion, add one row to [PROMOTION-LOG.md](PROMOTION-LOG.md).
